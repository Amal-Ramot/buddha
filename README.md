# דהרמה · Buddha Dharma

ממשק אינטראקטיבי בעברית שמרכז את תורת הבודהה: 30 נושאים ו־162 מושגים בשבעה שערים
(הבודהה, יסודות, הדרך, התודעה, תרגול, מסורות, כתבים).

**אתר חי:** https://amal-ramot.github.io/buddha/

## מה יש בפנים

- גלגלים אינטראקטיביים לדרך המתומנת, להתהוות המותנית ולנושאים נוספים
- עמוד לכל נושא, עם ציר זמן, רשימת מושגים וציטוט מהמקורות
- מדריך נשימה עם שלושה דפוסים
- מילון פאלי / סנסקריט עם חיפוש
- חיפוש מהיר בכל האתר (`Ctrl K` / `⌘ K`), מצב בהיר וכהה, RTL מלא

## טכנולוגיה

Next.js 16 (App Router, ייצוא סטטי) · React 19 · TypeScript · Tailwind CSS 4 · Motion.
כל התוכן נמצא ב־`src/data/dharma.ts`; הוספת נושא שם יוצרת לו עמוד, כרטיס וערכי מילון.

## פיתוח

```bash
npm install
npm run dev
```
